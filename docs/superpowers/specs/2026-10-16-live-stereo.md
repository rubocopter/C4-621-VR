# Bounded live stereo diagnostic

User authorizes continuing toward live stereo + head orientation, uses main, offline coop AC6 PID5440, PSVR2/SteamVR. Static depth-reprojected pair was fused successfully. Preserve current game files/resolution and mapped inactive DLLs. First prove a bounded 30-second stream before linking orientation. Existing source projection is fixed model; metric scale/asymmetric eyes/HUD remain experimental.

Producer: new uniquely named DLL, reuse observed command-list ledger and source discovery from frame_pair_probe. Three named shared DEFAULT buffers; each stores depth plane0 and packed color using copyable row footprints. Prebuilt private copy lists per slot/backbuffer appended to SAME eligible ExecuteCommandLists call. States restore exactly. No GPU waits, Map, files or resource creation in Execute callback. One DIRECT queue; unknown list invalidates depth, resize/failure stops. Collect ~2 seconds then stream <=60 seconds/F12. DLL/storage retained inactive.

Protocol: fixed mapped Header (Windows x64 aligned Interlocked fields), PID/version/LUID/dimensions/format/offsets/pitches; immutable after status=Ready. Three slot frame sequences + publication GetTickCount64 ticks. Named resources suffix _buffer0..2, _ready, _released. Producer signals shared ready fence with increasing frame id, then atomically publishes slot sequence. It reuses a slot only if ready and released fences both reach its prior id. Consumer single owner (Interlocked claim PID), last-consumed monotonic; chooses newest id > last, queue Wait ready, reads that buffer, returns it to COMMON, signals released id. Missing consumer fills ring then producer drops frames without blocking. Consumer latches selected slot until its own GPU completes. Closed stream can consume final frame but stale pixels must hide after 500ms.

Consumer: standalone D3D12 caller-owned device/DIRECT queue, same adapter LUID. Two 1280x720 eye buffers from padded depth+packed R10/RGBA/BGRA shared source using compute reference, baseline0.5 game units (not measured IPD). Index loads bounded including holes, original device-depth ordering. CPU pixel readback only test/one preview. Production blits buffer->OpenXR swapchain on GPU and returns target RENDER_TARGET, per-eye quads same geometry as successful static trial. Track Update() and freshness. Camera tracking initially disabled, then bounded existing15s probe after live image is verified; do not mix unverified changes in one human trial.

Evidence: deterministic ring tests, changing GPU fixture and skipped/backpressure frames, separate shared consumer device, exact color/depth correspondence and two eye outputs; review enqueue/ownership/lifetime; live monitor diagnostic first, then user-ready VR trial and feedback. No claims of metres, same-frame matrix binding, geometry per-eye render or long-term comfort.
